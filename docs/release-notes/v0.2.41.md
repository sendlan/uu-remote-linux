修复原生控制端连 Mac 无画面，GNOME 手机控制端新增手势滚动，控制端记住画质设置。/ Fixes the native viewer showing no picture from Mac hosts, adds gesture scrolling for phone viewers on GNOME, and remembers viewer quality settings.

### 修复 / Fixed
- **原生控制端连 Mac 被控端一直“连接中”、无画面（#136，感谢 @coolxll 二分定位）**：v0.2.40 在本地重置后只等 IDR，Mac 对 PLI 不回 IDR 时会一直丢帧。现在 H.264 I 片和恢复点 SEI 也可作为重启点，最多等待 1.5 秒后照常解码。
  Native viewer: after a local reset it accepted only IDR frames, so a Mac host that answers PLI without one stayed blank. I slices and recovery-point SEI now count, and the wait is capped at 1.5 s.

### 新增 / Added
- **GNOME（Portal）手机控制端手势（#134、#131，感谢 @spixyy7）**：触控模式下拖动即平滑滚动（终端里也能滚），按住 0.45 秒后拖动为选中，短按为点击；默认不再需要触摸屏授权。`UU_TOUCH_INPUT=touch` 改用真触控，`=0` 保持鼠标拖动。输入法 ASCII 直接按键输入。
  GNOME Portal phone viewers: drag scrolls smoothly (also in terminals), hold-then-drag selects, tap clicks, with no touchscreen consent by default; `UU_TOUCH_INPUT=touch` / `=0` select real touch or mouse drags.
- **控制端跨会话记住画质、帧率和真彩设置（#133，感谢 @spixyy7）**。/ The viewer remembers quality, frame rate and true-color choices.

### 验证范围 / Validation
单元测试与 CI。手机手势由贡献者在 Fedora 44 / GNOME 50.6 + 官方 Android 控制端实机验证；#136 的修复尚未连真实 Mac 被控端验证。

  LoongArch64 support with both `loong64` (Debian/Loongnix) and `loongarch64` (AOSC) deb packages — the same ABI 2.0 binary. Tested on Loongnix 25 / 3A6000 (X11 capture, VAAPI encoding, audio, file transfer, terminal).

  The release workflow builds LoongArch packages under QEMU (Debian loong64 container) and uploads them with every release; vendored webrtc/nix components upgraded for loongarch64 builds.
