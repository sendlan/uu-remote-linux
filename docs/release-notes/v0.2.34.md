修复网络波动后信令重连卡住，以及 Linux 控制端在平铺窗口管理器下画面空白。/ Fixes signaling reconnect stalling after a network hiccup, and the Linux viewer showing a blank window under tiling compositors.

### 修复 / Fixed
- **网络异常后停在 Acquired room signaling credentials（#115，感谢 @Changxi-M）**：信令 WebSocket 握手没有超时，网络半断时会无限等待，重连不再重试。现在握手限时 20 秒，超时后按原有退避重试。
  The signaling WebSocket handshake is now bounded to 20 s, so a stalled handshake falls back to the normal reconnect retry instead of hanging forever.
- **控制端窗口平铺后画面空白（#118，感谢 @shao-zhijie）**：Linux 控制端只在收到新解码帧时绘制，合成器调整窗口尺寸后静止画面不会重绘；在尚未收到首帧时，Wayland 也不会映射没有提交缓冲的窗口。现在窗口尺寸变化/重新显示时用最后一帧重绘，无帧时先画黑底。
  The Linux viewer now repaints the last frame after a compositor resize/expose, and paints a black frame before the first decoded frame so Wayland maps the window.

单元测试与 CI；#115、#118 的场景尚未实机复现，欢迎反馈。
