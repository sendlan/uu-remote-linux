### 优化 / Improved
- **Portal 取帧事件驱动（#193，关闭 #192）**：Portal VAAPI 推流循环由固定间隔休眠轮询改为条件变量等待新帧（单调时钟），新帧到达即编码，空闲时不再空转。/ The Portal VAAPI loop waits on a condition variable (monotonic clock) for new frames instead of sleep-polling, so frames are encoded as soon as they arrive and idle loops no longer spin.

感谢 @ferstar 提交这项优化。/ Thanks to @ferstar for this optimization.
